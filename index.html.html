Pengaturan permainan

Petunjuk bermain

  1. Pilih jenjang, materi, sumber soal, jumlah soal, dan waktu menjawab.
  2. Aktifkan kamera dan izinkan akses kamera saat diminta.
  3. Berdiri cukup jauh agar bahu dan pinggul terlihat, lalu ikuti kalibrasi.
  4. Bergerak ke sisi kiri untuk pilihan yang ditandai BENAR atau ke kanan untuk SALAH. Perhatikan legenda layar jika pemetaan sisi diubah.
  5. Tunggu umpan balik, baca penjelasan, lalu lanjut ke soal berikutnya.
  6. Jika kamera tidak tersedia, pilih mode tombol/keyboard.

Kamera digunakan untuk deteksi pose di perangkat. Aplikasi ini tidak merekam atau mengunggah video. Model dan pustaka MediaPipe dimuat melalui internet.

Manajemen konten

Kelola Bank Soal

Tambahkan soal sendiri tanpa mengubah kode HTML.

Input Banyak Soal Sekaligus

Tempel beberapa soal sekaligus. Gunakan satu baris untuk setiap soal dengan format: Pernyataan | Benar/Salah | Penjelasan | Materi. Contoh materi: Fikih, Akhlak, Akidah dan Asmaul Husna, Kisah Nabi.

Soal akan ditambahkan ke bank soal guru, disimpan di browser, dan dapat dipilih pada menu utama melalui Sumber Soal → Soal buatan guru.

Impor mengganti bank soal guru hanya setelah seluruh file tervalidasi. Bank bawaan tetap tersedia terpisah.
